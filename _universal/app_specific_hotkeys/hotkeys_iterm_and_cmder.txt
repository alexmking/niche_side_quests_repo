========================================================================
GREP
========================================================================
history | grep myWord                    |  searches the output of the 'histroy' command for the 'myWord' term
history | grep *.txt                     |  searches the output of the 'histroy' command for all .txt extension
grep -i myWord myFile.txt                |  search within the given file myFile.txt
grep -i myWord myFile1.txt, myFile2.txt  |  searches multiple files
GREP FLAGS (common ones)
grep -I myWord myFile.txt                |  IGNORE CASE SENSITIVITY: searches myFile.txt for 'myWord' but IGNORES CASE SENTIVITY
grep -v myWord myFile.txt                |  inverse-match: so it will show nayhting that does NOT include the target word
